# 邮件

[English](DETAIL.md) | 中文

通过 IMAP 读取邮箱、监听新邮件，并在 DeepSeek Harness 会话中发送经过审核的 multipart HTML 回复。插件在左侧边栏添加 **邮件** 入口，并向模型提供六个工具。

## 功能

- **读取邮件** — `mail_list` 列出文件夹中的最近邮件，包含发件人、主题、日期、未读状态、摘要和 UID。`mail_read` 返回解码后的纯文本正文、邮件头、附件名称，并可选返回 HTML 正文。
- **起草回复** — `mail_reply` 读取原邮件，默认回复给发件人或 `Reply-To`，设置 `In-Reply-To`/`References` 线程头，并保存 HTML 正文和自动生成的纯文本替代内容。
- **发送前审核** — 未受信任收件人的草稿会出现在 **邮件 → 审核**。你可以查看渲染后的 HTML、与原文对照、编辑主题和源码，然后选择 **批准并发送**、**保存更改** 或 **拒绝**。只有你能批准。
- **受信任收件人** — 在 **邮件 → 设置 → 审核策略** 中配置：
  - **除受信任收件人外均需审核**（默认）：所有收件人都被覆盖时才自动批准。
  - **始终审核**：所有草稿都等待审核。
  - **从不审核**：所有草稿自动批准。
- **后台监听** — 启用后每 30–300 秒轮询收件箱；新未读邮件会唤醒最近使用邮件工具的会话。来自本邮箱自身或带 `Auto-Submitted` 头的邮件会被跳过。
- **发送** — `mail_send` 通过 SMTP 发送草稿，并在服务器允许时向已发送文件夹追加副本。

## 配置邮箱

打开 **邮件 → 设置**，填写邮箱地址、显示名称、IMAP/SMTP 主机、端口、安全方式、用户名、密码以及收件箱/已发送文件夹。**测试连接** 不会发送邮件。密码保存在 DSH 凭据存储中，从不写入插件配置或会话事件。

要启用自动回复，打开 **邮件 → 设置 → 自动回复**，勾选 **在后台检查收件箱**，选择间隔并保存。启用时会记录当前邮箱位置，只处理之后到达的邮件。**立即检查** 可执行一次。监听会唤醒最近使用邮件工具的会话；没有活动会话时会在状态中提示。

## 审核规则

1. 让模型读取邮件，例如：*“读取我最近的三封邮件并总结。”*
2. 让模型用 HTML 回复。
3. `mail_reply` 的结果会说明是否需要审核。
4. 需要审核的草稿在 **邮件 → 审核** 中批准；Agent 无权批准。
5. 受信任收件人的草稿自动批准，模型可直接调用 `mail_send`。

## 限制

- 每个安装只支持一个邮箱。
- 不支持附件、OAuth、IMAP IDLE 或服务器草稿箱同步。
- 纯文本提取是启发式的。
- 已发送副本写入是尽力而为。
- 监听基于轮询，仅在 DSH 运行且有活动会话时工作。
- 监听入队后会越过该 UID；模型后续失败不会自动重试。
- 审核预览会阻止远程图片和脚本。
- 面板提供英文和简体中文。
